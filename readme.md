# Linux and Git Command Cheat Sheet
Cheat sheet showcasing basic knowledge of basic Linux and Git commands
#Linux Commands
1. ls
Lists the files and folders in the current directory
Ex:ls
2. ls -l
Lists files and folders in long format, showing details like permissions, owner, file size, and date modified.
Ex:ls -l
3. cd
Changes the current directory.
Ex:cd Documentns
4. pwd
Prints the full path of the current working directory.
Ex:pwd
5. mkdir
Creates a new directory or folder.
Ex:mkdir new_folder
6. touch
Creates a new empty file.
Ex:touch notes.txt
7. cp
Copies a file from one location to another.
Ex:cp notes.txt backup_notes.txt
8. mv
Moves or renames a file.
Ex:mv oldname.txt newname.txt
